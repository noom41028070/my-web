## 一、安裝方式

這些都是 Firehaha 的插件檔（`.js`），使用方式跟你平常安裝插件一樣：把程式碼存成 `.js` 檔案，透過 Firehaha 的插件管理介面載入／啟用即可。六個插件是獨立的，你可以只裝需要的幾個，不用全裝。

## 二、六個插件分別做什麼

| 插件 | 作用 |
|---|---|
| **官方屬性／技能原生修正** | 底層插件，負責解析正文中的 `[屬性:名稱=數值]`、`[修正值:名稱=數值]`、`[技能:名稱=數值]`、`[技能修正值:名稱=數值]` 標籤，把數值寫進存檔，同時修正返回按鈕會讓數值倒退的問題。**這個必裝**，其他插件都依賴它建立的資料。 |
| **數值文字顯示** | 正文顯示 `{數值:名稱}` |
| **屬性文字顯示** | 正文顯示 `{屬性:名稱}` |
| **技能文字顯示** | 正文顯示 `{技能:名稱}` |
| **屬性列表顯示** | 正文顯示 `{屬性列表}`，一次列出所有屬性 |
| **技能列表顯示** | 正文顯示 `{技能列表}`，一次列出所有技能 |

## 三、實際寫作範例

假設你在某一頁的正文裡寫：

```
你出生在邊境的小村莊。

[屬性:力量=10]
[屬性:敏捷=8]
[技能:潛行=3]
[技能:談判=5]
```

這些方括號標籤**不會顯示在畫面上**（原生系統本來就會把它們吃掉），但會把力量、敏捷、潛行、談判這幾個數值記錄進存檔。

之後在任何一頁（同一頁或後面的頁面）想秀出數值，就用大括號標籤：

```
你的力量是 {屬性:力量}，敏捷是 {屬性:敏捷}。
潛行能力：{技能:潛行}
```

畫面上會顯示成：

```
你的力量是 10，敏捷是 8。
潛行能力：3
```

如果想一次列出全部屬性／技能，不用每個都手打：

```
角色屬性：{屬性列表}
角色技能：{技能列表}
```

會自動顯示成：

```
角色屬性：力量: 10、敏捷: 8
角色技能：潛行: 3、談判: 5
```

## 四、調整數值的加減（修正值）

如果某一頁想「加成」而不是「設定成固定值」，用修正值標籤：

```
[修正值:力量=+2]
```

這個是疊加到力量的修正欄位（`adventure.modifiers`），不會覆蓋原本的 `[屬性:力量=10]`。不過目前的顯示插件（`{屬性:名稱}`）只讀 `attributes`，**不會自動把 modifiers 加進去**——如果你想要顯示「基礎值＋修正值＝最終值」，這需要另外再寫一個插件把兩者相加後顯示。要的話跟我說，我可以幫你補一個 `{屬性最終:名稱}` 之類的標籤。

## 五、幾個要注意的地方

1. **標籤裡的名稱要完全一致**，包含空格。`[屬性:力量=10]` 跟之後要用 `{屬性:力量}` 顯示，「力量」兩字要一模一樣，前後不要多打空白（雖然程式會自動 trim，但保險起見統一寫法比較不容易出錯）。
2. **`[屬性:...]` 只在該頁被「讀到」時才會套用一次**，不會因為玩家按返回又重複套用或錯亂——這正是第一個「原生修正」插件解決的問題。
3. **數值不存在時顯示 `0`**，例如你還沒設定過「智力」，寫 `{屬性:智力}` 會顯示 `0` 而不是報錯或顯示空白。
4. **列表顯示可以自訂分隔符**：`{屬性列表:／｜ = }` 這種寫法，`｜` 前面是屬性之間的分隔符（範例是全形斜線 `／`），後面是名稱與數值間的分隔符（範例是 ` = `）。不需要自訂就直接用 `{屬性列表}`，預設是頓號＋冒號。
