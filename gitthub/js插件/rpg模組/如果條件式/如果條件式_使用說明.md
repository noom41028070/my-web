# [如果] 條件式 使用說明

## 基本語法

```
[如果:數值:變數名稱|比較字|數字]
條件成立時顯示的內容
[否則]
條件不成立時顯示的內容
[/如果]
```

也可以用在「屬性」「技能」:

```
[如果:屬性:力量|超過|15]
[如果:技能:開鎖|未滿|60]
```

---

## 比較字對照表

| 意思 | 中文寫法 | 英文縮寫(等效) |
|---|---|---|
| 大於等於(≥) | `至少` / `以上` | GE |
| 小於等於(≤) | `至多` / `以下` | LE |
| 大於(>) | `超過` / `大於` | GT |
| 小於(<) | `未滿` / `小於` | LT |
| 等於(=) | `等於` | EQ |
| 不等於(≠) | `不等於` | NE |

**⚠️ 常見誤區:「不等於 0」≠「大於 0」**

想判斷「還活著 / 死了」這種情境,**不要用「不等於 0」**,因為負數(-1、-5…)也算「不等於 0」,會被誤判成「還活著」。

正確寫法應該用「大於」或「至少|1」:

```
[如果:數值:HP|大於|0]
你還活著
[否則]
你死了
[/如果]
```

---

## ⚠️ 最重要的規則:同一頁裡,「判斷」永遠比「數值變化」先發生

外掛的執行順序是**固定**的:

1. 先讀這一頁的內容,用**目前的**數值判斷所有 `[如果]`,決定要留哪段文字
2. 判斷完之後,才真的去執行 `[數值]` `[增加]` `[減少]` 這些會改變數值的標籤

**結果:如果 `[減少:HP:10]` 跟 `[如果:數值:HP|大於|0]` 寫在同一頁,`[如果]` 判斷時讀到的還是「扣血前」的舊值,不會是扣完之後的新值。**

### ❌ 錯誤示範(同頁扣血 + 同頁判斷 → 判斷結果會是舊值)

```
[減少:HP:10]
[如果:數值:HP|大於|0]
你還活著
[否則]
你死了
[/如果]
```

### ✅ 正確作法:扣血跟判斷分開兩頁

**這一頁(扣血)**
```
[減少:HP:10]
你被攻擊了。
```

**下一頁(判斷)**
```
[如果:數值:HP|大於|0]
你還活著
[否則]
你死了
[/如果]
```

只要中間隔一頁,讓玩家點「下一頁」翻過去,扣血就已經確定生效,下一頁判斷時讀到的才會是正確的新數值。

---

## 除錯口訣

寫故事時如果 `[如果]` 判斷結果怪怪的,先照這個順序檢查:

1. **這一頁裡,`[如果]` 是不是跟改數值的標籤(`[數值]` `[增加]` `[減少]`)寫在同一頁?**
   → 是的話,先把它們拆到不同頁試試看。

2. **比較字用對了嗎?**
   → 想判斷「活著/死亡」這種情境時,用「大於/至少」,不要用「不等於」。

3. **變數名稱有沒有打錯、大小寫不一致?**
   → 可以在測試閱讀視窗的 Console 打 `memorySave.adventure.values` 看實際存的數值和名稱。
