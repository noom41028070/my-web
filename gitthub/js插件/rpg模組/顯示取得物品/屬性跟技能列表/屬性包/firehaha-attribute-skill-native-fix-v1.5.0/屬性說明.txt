# 官方屬性／技能系統

## 1. 設定角色能力

```text
===角色建立===

[屬性:力量=60]
[屬性:敏捷=55]
[屬性:SAN=70]

[技能:偵查=40]
[技能:圖書館=35]
[技能:說服=50]
```

冒險紀錄：

```text
力量：60
敏捷：55
SAN：70

偵查：40
圖書館：35
說服：50
```

---

# 2. 劇情變化

例如主角受傷：

```text
你從高處摔下。

[屬性:力量=45]
```

閱讀器會直接更新：

```text
力量：45
```

---

學會新技能：

```text
你接受了調查員訓練。

[技能:偵查=60]
```

變成：

```text
偵查：60
```

---

# 3. 裝備（修正值）

拿到神劍：

```text
你裝備了神劍。

[修正值:力量=10]
```

冒險紀錄：

```text
力量 45 (+10)
```

實際骰點：

```text
力量 = 55
```

---

被詛咒：

```text
[修正值:力量=-15]
```

變成：

```text
力量 45 (-15)
```

實際骰點：

```text
力量 = 30
```

---

技能 Buff：

```text
[技能修正值:偵查=20]
```

冒險紀錄：

```text
偵查 60 (+20)
```

實際判定：

```text
80
```

---

# 4. CoC 判定範例

```text
門被鎖住。

請骰 1D100

若 ≤ 力量
成功推開門。

若 > 力量
失敗。
```

目前能力：

```text
力量 45 (+10)
```

實際能力：

```text
55
```

骰：

```text
1D100 = 41
```

成功。

# 5. 推薦寫法

角色建立：

```text
[屬性:力量=60]
[屬性:敏捷=55]
[技能:偵查=40]
```

拿到武器：

```text
[修正值:力量=10]
```

學會技能：

```text
[技能:偵查=50]
```

受傷：

```text
[屬性:力量=45]
```

## 為什麼推薦這種設計？

這個系統採用的是**「目前狀態」**的概念，而不是一直累加。

例如劇情走到這一頁，只要寫：

```text
[屬性:力量=45]
```

閱讀器就會知道「現在力量就是 45」，作者不用回頭計算之前到底加了幾次、減了幾次。

我覺得這也是你這套編輯器最大的特色：**每一頁都能直接宣告角色目前的狀態**，對互動小說和 Gamebook 來說，比事件累加式的設計更直覺、更容易維護。
